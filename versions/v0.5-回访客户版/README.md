# v0.5 老版本 · 封存说明

> 封存时间：2026-09-01
> 版本定位：**回访客户版** —— 仅面向"已有商城客户"的回访激活业务
> 包含文件：`开发计划.md`、`需求问答卷.md`、`design-demo/demo-miniapp.html`、`design-demo/demo-admin.html`

## 封存原因

老板决定在 0.6 版本加入"纯新客户开发"（未入商城客户）功能，与回访客户并存。0.5 版本作为纯回访客户的完整设计方案封存在此，**保持原样不再修改**。

## 0.5 版本功能范围（已闭环）

1. 客户导入：原始客户表 / 商城客户名单（47 列），追加 / 替换模式，自动地址解析补坐标；
2. 任务：三种选客户方式（列表 / 名单导入 / 地图点选）可混用、完成天数 1~7 天排期、草稿→发送、管理员预规划路线、业务员可重规划；
3. 拜访记录：定位校验（阈值可配、缺坐标跳过）、拍照、多段录音（业务员不可删、管理员可删）、时长自动记录、样品字段、8 种拜访结果、离线提交；
4. 回访效果：回访后下单率（MVP 口径）、业务员排行、客户级明细详情、按拜访结果过滤；
5. 人员管理：业务员增删改停、管理员账号（预置超级管理员卿燕，人员管理仅超管可见）；
6. 数据备份：每日 02:00 自动备份、后台下载；
7. 订阅消息：新任务通知；
8. 界面：聚火橙设计规范（开发计划第 16 节），两个 HTML 演示可交互。

## 与 0.6 的关系

0.6 以 0.5 为基线演进（根目录文件继续开发），主要新增：客户类型（商城客户/新客户）、开发转化链路（入商城认领：名单综合模糊对比+手动标记）、拜访结果按类型动态显示、任务拜访目的、报表按类型分组。最终用哪个版本由老板选择。
