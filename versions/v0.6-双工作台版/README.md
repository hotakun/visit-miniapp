## 与 v0.5 的关系

- v0.5（versions/v0.5-回访客户版/）：纯回访客户版，已封存不再修改；
- v0.6（本目录）：以 v0.5 为基线演进，新增"纯新客户开发"业务线，与回访激活**双工作台并存**；
- **最终用哪个版本由老板选择**：两个版本都是完整成稿，可分别独立开发。

## 0.6 相对 0.5 的核心新增（概要）

1. **客户类型双轨**：customerType = mall（商城客户）/ new（新客户）；新客户表导入（店名/区域/地址/联系人/手机号可空/备注，管理员均可导入，后台也可手动新增）；
2. **双工作台入口**：登录后选择页（🔥 回访工作台 / 🌱 新客开发工作台 / 全部总览）；进入后各页面逻辑、文案、指标全部随工作台切换（详见开发计划 16.8 差异矩阵）；
3. **拜访结果按类型动态显示**：新客户多一项"已注册商城"（先注册、后下单）；
4. **入商城认领**：每周商城名单导入后综合模糊比对（手机号精确 > 经纬度 ≤300 米 > 店名相似 > 联系人/地址辅助），高分自动认领、中分待确认核对、低分忽略；手动标记/撤销/修正兜底；认领后客户自动换轨至商城客户口径；
5. **新客开发指标**：添加商城成功率（入商城÷拜访）、新客下单率（首单÷入商城）、开发漏斗、业务员开发排行；
6. **任务拜访目的**：按工作台收窄（回访工作台仅"激活回访"，新客开发工作台仅"新客开发"，全部总览二选一）；
7. **任务管理三层结构**：任务列表（状态化操作）→ 任务详情（效果小结/天计划/地图轨迹/本任务拜访记录）→ 新建/编辑向导（预填）；进行中任务实时编辑+推送"任务已更新"；撤回回草稿可重发；
8. **客户导出**：36 列详细分列 Excel 留档，随筛选导出；
9. **人员管理**：业务员增删改停 + 管理员账号（预置唯一超级管理员卿燕，人员管理菜单仅超管可见）；
10. **报表双口径**：回访工作台=回访效果（回访后下单率）；新客开发工作台=拜访效果（开发转化率+首单率）。
