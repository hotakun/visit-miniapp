# 微信开发者工具操作指引（第一期开工）

> 按下面 5 步操作，完成后把**云环境 ID** 发回来即可进入功能开发。

## 第 1 步：导入项目

1. 打开微信开发者工具（你已经打开了）；
2. 首页点「**导入**」（或菜单 项目 → 导入项目）；
3. 目录选择：`D:\WFR\visit-miniapp\miniprogram`；
4. AppID 会自动读取（wxcfdfcfffcf321fc2），无需手填；
5. 点「导入」→ 等编译，看到"聚火拜访"橙底欢迎页即成功。

## 第 2 步：开通云开发

1. 开发者工具顶部点「**云开发**」按钮（云朵图标）；
2. 首次会提示开通 → 点「开通」（选**按量付费**，开通不花钱，用多少算多少）；
3. 环境名称随意填（如 `juhuo`），点确定，等 1~2 分钟创建完成；
4. 创建完成后，云开发控制台**左上角**能看到环境 ID（形如 `juhuo-3gxxxxxx`）；
5. **把环境 ID 发给我**（或告诉我后我自己回填）。

## 第 3 步：上传并部署云函数（环境 ID 回填后）

1. 在开发者工具左侧文件树，右键 `cloudfunctions/ping` → 「**上传并部署：云端安装依赖**」；
2. 同样操作 `cloudfunctions/init`；
3. 右键 `cloudfunctions/init` → 「**云端测试**」→ 直接点「运行」→ 看到 `ok: true` 和创建日志 = 数据库和账号初始化成功。

## 第 4 步：验证首页连通

- 模拟器里点首页的「检查云环境连接」按钮 → 弹"云函数连通 ✓"即全部就绪。

## 第 5 步：把初始化结果告诉我

- 云端测试 `init` 的运行日志里应有：管理员 卿燕（qingyan）已创建 + 丰炳全/程绍君/宋子军已创建 + 10 个集合就绪。
- 截个图发我，或直接把日志贴给我。

## 常见问题

| 现象 | 解决 |
|---|---|
| 导入后报"appid 不合法" | 确认 mp 后台该小程序存在且 AppID 无误 |
| 云开发按钮是灰的 | 确认登录的微信号是该小程序的管理员/开发者 |
| 云函数上传失败 | 检查网络；右键选"云端安装依赖"而不是"上传" |
| 首页点按钮提示云环境未就绪 | 环境 ID 还没回填到 `app.js` 的 `CLOUD_ENV`，发我环境 ID 即可 |
