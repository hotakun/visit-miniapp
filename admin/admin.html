🏙 回填三层字段（城市 / 区域 / 商圈）

        

          给已有客户补上 city / district / bizCircle 三个字段，用来做「城市 → 区域 → 商圈」的分层管理。

          新导入的客户会自动带上这三个字段，这个按钮是给老数据用的（或者以后取数规则改了、要重跑一遍）。

📍 定位与拜访

        

          
拜访定位校验

          

            

              
              
              
              
              
              
              
            

            
业务员提交拜访时校验与客户的距离：勾选后按 1~500 米阈值校验，填 0 或不勾选=关闭；定位失败直接拦截提交。
正常页面刷新=普通页面的定位刷新频率（默认 30 秒）；重要页面刷新=拜访记录等重要定位页面的频率（默认 15 秒）。定位失败静默保留旧数字。
拜访录音上限=手机端现场录音单段最长时间（默认 5 分钟），到点自动停止。
拜访时长上限=一次拜访最长计时（默认 1 小时）：到点前 5 分钟提醒；已选结果自动提交（跳过距离、无照片录音）、未选结果自动取消，均写入任务流程档案。

          

        

        
        

          
定位上报

          

            

              
              
            

            

              定位轨迹：开启＝手机端记录并上传行踪轨迹，后台可回放全天路线、看每段停留，消耗调用较多；关闭＝不再记录任何轨迹（后台「轨迹回放 / 当天轨迹」无数据），但最新位置仍按下一项执行 → 定位类调用大幅下降。

              最新位置上报：开启＝后台「位置监控」能看到业务员当前在哪、是否在拜访中；关闭＝后台只保留最后一次已知位置（不再刷新）→ 定位类调用降到最低。
            

          

        

        

          
定位轨迹参数

          

            

              
              
              
              
              
            

            
工作档位＝工作时段（拜访中/平时）的上报频率，默认 30S/120S 最省调用（每 30 秒一个点，只能看大致动线与停留，看不出秒级行踪）；非工作档位＝非工作时段的联动降频、绝不空转；轨迹保留＝云端轨迹片段保留天数（默认 30），到期自动清理。

          

        

        

          
现场证据

          

            

              
              
              
              
            

            
照片上限＝一次拜访最多上传张数（默认 9）；允许录音＝关闭后手机端不显示录音区、云端拒收录音；强制拍至少 1 张＝开启后提交拜访必须有照片（默认关）。

          

        

        

          
手机端显示

          

            

              
              
              
              
            

            
手机端界面开关：平台参考图＝新客户页是否显示平台抓取的参考图；坐标报错入口＝客户页「📍报错」按钮；审核轮询＝手机端审核状态观察员（关闭可省调用）；可见范围＝业务员能否看到非本任务客户。
（2026-09-11 老板定：不做电话打码 —— 正式业务员一律看到完整电话号码，仅游客打码）

用量告警模板

          

            

              
              
              
              
              
            

            

              
              
            

            

              模板 ID 不在界面显示明文（2026-09-12 定，避免被看到/误改）：输入框留空＝不修改，要更换模板时把新 ID 整段粘贴进来再点保存；不想要了就点「清除」。当前配置状态显示在按钮右侧。

              管理员信息收件人（2026-09-12 定）：系统/管理类通知（用量告警等）只发给这里填的手机号，不会自动发给系统管理员/老板账号绑定的微信（避免打扰业务方）。填多个用逗号隔开；留空 = 这类通知不发送。手机号对应的账号须已绑定服务号 OpenID 才会收到。

              模板：「实时交易提醒」（编号 47862）用于「本月云调用」超红线时发提醒。字段映射（写死在云端）：商户名称=聚火拜访 · 交易类型=云开发调用用量提醒 · 交易金额=本月用量（万次）· 交易时间=发送时刻 · 商品名称=用量百分比提示。

              ⚠️「交易金额」是 amount 类型只能填数字；模板 ID 开头那截 -- 也是 ID 的一部分。清除模板 ID 后告警将回落到「新任务提醒」的模板。

⚠️ 危险区

将清空全部任务、拜访记录、坐标报错申请、转写文本，所有客户状态恢复「待回访」。拜访照片与录音文件将一并从云存储删除。客户档案、批次、账号、系统设置、商城客户名单保留。
