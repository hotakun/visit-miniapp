## 常见问题

| 现象 | 解决 |
|---|---|
| check.js 报 invalid appsecret | AppSecret 复制不完整；mp 后台重置再复制 |
| check.js 报 40164 | mp 后台「开发设置 → IP 白名单」关闭或加公网 IP |
| check.js 报 85088 | 该 AppID 未开通云开发 |
| 业务员手机登录被识别为管理员 | 该微信绑定了管理员账号；业务员需用自己微信首次绑定 |
| 建任务后业务员没收到订阅消息 | 业务员需先在首页点「🔔 订阅任务提醒」授权一次 |

> AppSecret 只存本机 config.json，勿外发。
