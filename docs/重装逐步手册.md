## 步骤 6 · WSL（⚠️ 最容易装错的一步）

### 6.1 先确认虚拟化已开

```powershell
Get-CimInstance Win32_ComputerSystem | Select HypervisorPresent
```
**期望**：`True`

如果 `False` → 进 BIOS 打开 Intel VT-x。

### 6.2 装 WSL 到 D 盘（⚠️ 必须带 `--location`）

```powershell
wsl --install -d Ubuntu-24.04 --location "D:\WSL\Ubuntu"
```

> ⚠️ **不带 `--location` 会全部装在 C 盘（几十 GB），事后要 export/import 搬移。**

### 6.3 重启

重启后会自动启动 Ubuntu 初始化，**设置用户名和密码**（记好，后面 sudo 要用）。

### 6.4 验收

```powershell
wsl -d Ubuntu-24.04 -- echo ok
```
**期望**：`ok`

```powershell
Get-ChildItem D:\WSL -Recurse -Filter *.vhdx
```
**期望**：能看到 `ext4.vhdx` 在 `D:\WSL` 下

### ✅ 步骤 6 验收清单
- [ ] `wsl -d Ubuntu-24.04 -- echo ok` 输出 `ok`
- [ ] `D:\WSL\Ubuntu\ext4.vhdx` 存在

```powershell
$src = 'D:\WFR\备份-重装前\reasonix'
$dst = "$env:APPDATA\reasonix"

# 顶层配置（含 .env 的 9 个 API Key）
Get-ChildItem $src -File | Where-Object { $_.Name -ne 'README-恢复说明.md' } | Copy-Item -Destination $dst -Force

# 子目录
foreach ($d in 'global','state','desktop','global-workspace') {
  if (Test-Path "$src\$d") {
    New-Item -ItemType Directory -Path "$dst\$d" -Force
    Get-ChildItem "$src\$d" -File | Copy-Item -Destination "$dst\$d" -Force
  }
}

# ⭐⭐ 恢复 AI 记忆（49 个业务口径）
$srcMem = "$src\projects-memory"
$baseMem = "$dst\projects"
Get-ChildItem $srcMem -Directory | ForEach-Object {
  $memDir = Join-Path (Join-Path $baseMem $_.Name) 'memory'
  New-Item -ItemType Directory -Path $memDir -Force
  Get-ChildItem $_.FullName -File | Copy-Item -Destination $memDir -Force
  Write-Host "恢复 $($_.Name): $((Get-ChildItem $_.FullName -File).Count) 个 md"
}
```
