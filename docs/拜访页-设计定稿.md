## 一、这是个什么页

业务员开始拜访后的**执行页**：现场拍照 / 现场录音 / 填样品物料 / 写拜访记录 / 选拜访结果 → 提交。

**区块顺序**（2026-09-08 老板定）：
客户名 + 计时 → ⏰超时预警 → 📷现场拍照 → 🎙️现场录音 → 📦样品/物料 → ✍️拜访记录 → 🎯拜访结果 → 底部提交

五个区块**都可点标题栏折叠**，收起时右侧留一行状态摘要（「已拍 4/9 张」「2 段 · 合计 01:23」）。
**默认五个区块全部收起**（⚠️ 2026-09-13 老板改：原来是"默认展开拍照 + 录音"，现在一律收起 ——
       进去先看到五个标题栏，点哪个展开哪个；`visit.js` 的 `foldPic` / `foldRec` 由 `false` 改成了 `true`）。

## 二、老板拍板的口径（2026-09-12，勿翻案）

### 1. 现场照片 —— 一行三个

- 格子 **96×72px 固定像素**（真机 **192×144 rpx**），`flex-wrap` 自动换行 → **一行三个**
- 上限 **9 张**（后台设置页可配 3/6/9/15）
- 每格：左下角**纯描边序号**、右上角 ✕ 删除、点图看大图
- ⚠️ 演示稿里踩过的坑：手机外壳有 8px 边框，全局 `border-box` 会把内容区挤窄 16px，
  导致一行只能放两个 → 给 `.phone` 单独设 `box-sizing:content-box` 解决

### 2. 录音段序号 —— 数字后面带点

`1.` `2.` `3.`（不是 `1` `2` `3`）

### 3. 转写勾选框 —— 不要白底方块

| | 样子 |
|---|---|
| 未勾选 | **透明圆环**（半透明白 2px 边、空心、无底色） |
| 勾选 | **白圆 + 绿勾** |

（原来是白底方块 + 白边框，在深绿渐变卡上像贴了张白纸，老板说难看。）

### 4. 「开始转录」按钮 —— 提交后变灰、不消失

- 点之前：白底、深灰字、可点
- 点之后：**按钮还在**，变**灰**（底 `#F2F4F7`、字 `#B7BEC7`、边 `#E9ECF1`）表示不能点，
  旁边显示「已提交 N 段转写，请稍候…」
- 再点无反应（点击处理里直接 return）

（曾改成"提交后按钮消失"，老板要求改回来 —— **要留着，灰掉就行**。）

### 5. 卡片描边 —— 1px 与标题栏同色系

| 卡片 | 标题栏底色 | 描边色 |
|---|---|---|
| 📷 现场拍照 | `#F7FAFD` 雾蓝 | `#E3EDF7` |
| 🎙️ 现场录音 | `#F8F7FD` 雾紫 | `#E8E5F7` |
| 📦 样品/物料 | `#FDFAF6` 雾杏 | `#F5EAD9` |
| ✍️ 拜访记录 | `#F7FBF8` 雾绿 | `#E2F1E8` |
| 🎯 拜访结果 | `#FDF8F9` 雾玫 | `#F7E6EA` |

描边用**同色系深一档**（标题栏那几个色几乎是全白，直接拿来当描边看不见）。

### 6. 拜访结果标签 —— **一套 10 项**，全部不带图标（⚠️ 2026-09-23 更新）

```
加入商城    需要样品    已下单     不愿改
有抵触      联系不上    闭店·搬迁   其他
已签约商城   未签约        ← 这两项【只对"未入商城"的客户显示】
```

⚠️ **2026-09-23（按修正 003 明确）—— 不再是"两套标签"**：

- **定义只有一套 10 项**（`加入商城 / 需要样品 / 已下单 / 不愿改 / 有抵触 / 联系不上 / 闭店·搬迁 / 其他 / 已签约商城 / 未签约`）
- **云端一律宽校验收 10 项**（过滤只是"少给选项"，**不是安全边界**）
- **显示时按数据过滤**：`已签约商城` / `未签约` **只对"未入商城"的客户出现**
- 差异只由"这家客户有没有入商城"决定"显示哪几项" —— 这正是修正 001「共用一套表达、数据各自不同」的字面执行
- ⚠️ **落地状态**：`visit.js:7-8` 与 `visits/index.js:7-8` **目前仍是 `MALL` / `NEW` 两套常量**（修正 003 的 4 处落地**尚未执行**）—— 照本文设计、按修正 003 落地

## 四、落地注意（改真机的时候）

这是**容易漏**的地方 —— 演示稿只改了样子，真机要生效还得同步：

1. **`visit.js` 的 `MALL` / `NEW` 数组** —— 结果标签现在**仍是这两个常量**（`MALL` 8 项 / `NEW` = `[...MALL,'已签约商城','未签约']` 10 项）。
   ⚠️ 按**修正 003** 要**合并成一套 10 项常量**，取值处（`visit.js:88`）改成"按判据过滤后的列表"；
   `visits/index.js:7-8` / `:259` 同步合并（**云函数之间不能共享代码，两边要逐字一致**，见修正 003 落地清单）
2. **`PRAISE` 提交话语库** —— 按结果名索引。⚠️ **2026-09-23 更正**：`PRAISE` **现在已经是 10 项全量**（含 `'已签约商城'` / `'未签约'`）；
   旧 key（`'极有意向'` / `'有意向'` / `'无需求'` / `'已注册商城'`）**已全部作废、代码里 0 残留** —— 不要再照旧 key 去改
3. **服务号通知文案映射** —— 同样是按结果名映射的（旧名已作废）
4. **`visit.wxss`** —— 勾选框 `.ri-ck`、按钮 `.trgo.busy`、卡片描边 `.blk-*`、弹窗 `.block-msg2` / `.block-sub`
5. **WXML 换行不能写 `<br>`**（项目铁律：只用 view/text）→ 拆成两个 `<view>`
6. **`visit.wxml` 的 `.ri-idx`** 里 `{{index + 1}}` 要改成 `{{index + 1}}.`
